# export

Use --file=<private path> to export all eight record types. The command refuses to overwrite a file. Keep native database backups too. This JSON export has no automatic restore command.

Start with the relevant read and run the one CLI: `npm run assortment -- export --json`. For writes, supply the required fields above and the real operator. Use help for the complete flags. List ambiguous candidates and let the operator select. Present dates, currency, unknown values and source limitations with the result. Never send, publish or change an external system.
