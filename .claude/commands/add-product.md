# add-product

Use --sku, --name, --category, optional --brand and --actor. Keep supplier SKU codes as text. Check products first to avoid a duplicate.

Start with the relevant read and run the one CLI: `npm run assortment -- add-product --json`. For writes, supply the required fields above and the real operator. Use help for the complete flags. List ambiguous candidates and let the operator select. Present dates, currency, unknown values and source limitations with the result. Never send, publish or change an external system.
