# Selection evidence

Checked 2026-11-03. DotActiv is a new retail-assortment-planning family in the rebuild registry. This run already built electronics test records and pricing research, so both were excluded.

The vendor's [pricing page](https://dotactiv.com/pricing) lists Enterprise at $4,500 per licence per year and Pro at $2,000. Five Enterprise licences imply $22,500 a year before local tax. That is a seat-count scenario, not a customer invoice. The current page uses a dollar sign without specifying the currency. We retain that qualification and make no NZD, AUD or USD claim. The public store pricing link could not be fetched reliably in this run.

Scores, one to five: annual bill 3; data-shaped 4; our buyers 2; search demand 2; one-session buildable 4; import path 4. Total 19/30. Data shape and buildability refer to the range-review scope. Visual planogram editing is outside it.

The available customer references and CRM snapshots had no verified DotActiv buyer match. Live CRM was not accessed. Search returned alternative list pages, but no measured search volume was available. These gaps reduce the buyer and demand scores. They must not be converted into customer or traffic claims.

Other screened candidate: VWO, web experimentation. Scores 1, 3, 2, 3, 2, 4 = 15/30. [Its current pricing page](https://vwo.com/pricing/) did not disclose a five-figure annual price. Serving experiments needs a separate delivery layer, so it was not selected. Convert's [published entry plans](https://www.convert.com/pricing/) were below the annual-bill threshold, so its family was also not selected. No queue entry was created for either.

DotActiv's [assortment page](https://dotactiv.com/assortment-planning-software/) establishes the category-planning scope. The [Product Report export announcement](https://dotactiv.com/blog/powerbase-updates-for-january-2020) establishes an Excel export path. Detailed [export help](https://powerbase.dotactiv.com/knowledge-base/export-reports/) requires member access. This build therefore requires an explicit mapping of the actual report columns.

DotActiv already offers analytics and an assistant. We make no claim that it cannot answer the questions this base answers. The distinction is ownership of the records, calculations and review workflow. This is a useful range-review base, not a feature-for-feature replacement for the vendor's full suite.
