# category-review

Review category sales and margin by store, cluster, currency and exact reporting window. A category with any missing cost has unknown total margin. Do not rank stores with different windows as if they were comparable.

Start with the relevant read and run the one CLI: `npm run assortment -- category-review --store="<store code or ID>" --json`. For writes, supply the required fields above and the real operator. Use help for the complete flags. List ambiguous candidates and let the operator select. Present dates, currency, unknown values and source limitations with the result. Never send, publish or change an external system.
