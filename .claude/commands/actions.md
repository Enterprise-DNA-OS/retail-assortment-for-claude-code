# actions

Read action owners, due dates and closure reasons. Never describe an open action as complete.

Start with the relevant read and run the one CLI: `npm run assortment -- actions --store="<store code or ID>" --json`. For writes, supply the required fields above and the real operator. Use help for the complete flags. List ambiguous candidates and let the operator select. Present dates, currency, unknown values and source limitations with the result. Never send, publish or change an external system.
