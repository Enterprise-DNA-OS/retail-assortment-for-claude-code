# products

Read the product register. SKU codes preserve leading zeros. Product names can repeat, so use the ID when a match is ambiguous.

Start with the relevant read and run the one CLI: `npm run assortment -- products --json`. For writes, supply the required fields above and the real operator. Use help for the complete flags. List ambiguous candidates and let the operator select. Present dates, currency, unknown values and source limitations with the result. Never send, publish or change an external system.
