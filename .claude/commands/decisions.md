# decisions

Read the recommendation, rationale and frozen evidence. A saved decision is a review record and never changes the approved range automatically.

Start with the relevant read and run the one CLI: `npm run assortment -- decisions --store="<store code or ID>" --json`. For writes, supply the required fields above and the real operator. Use help for the complete flags. List ambiguous candidates and let the operator select. Present dates, currency, unknown values and source limitations with the result. Never send, publish or change an external system.
