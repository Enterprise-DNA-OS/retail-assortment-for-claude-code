# attention

Read overdue reviews, report freshness and overdue follow-up. The 14-day freshness interval is local policy. Assign work through add-action only when the operator requests it.

Start with the relevant read and run the one CLI: `npm run assortment -- attention --store="<store code or ID>" --json`. For writes, supply the required fields above and the real operator. Use help for the complete flags. List ambiguous candidates and let the operator select. Present dates, currency, unknown values and source limitations with the result. Never send, publish or change an external system.
