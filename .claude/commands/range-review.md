# range-review

Read the latest report for the selected store. Show its dates, currency, active range status and missing costs. Reported products are not automatically added to the approved range.

Start with the relevant read and run the one CLI: `npm run assortment -- range-review --store="<store code or ID>" --json`. For writes, supply the required fields above and the real operator. Use help for the complete flags. List ambiguous candidates and let the operator select. Present dates, currency, unknown values and source limitations with the result. Never send, publish or change an external system.
