# margin-review

Show selling value, recorded cost, gross margin and margin percent. Negative gross margin is visible. Missing cost and zero sales do not become zero percent margin.

Start with the relevant read and run the one CLI: `npm run assortment -- margin-review --store="<store code or ID>" --json`. For writes, supply the required fields above and the real operator. Use help for the complete flags. List ambiguous candidates and let the operator select. Present dates, currency, unknown values and source limitations with the result. Never send, publish or change an external system.
