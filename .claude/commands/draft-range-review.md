# draft-range-review

Use --store to create a private review draft from range-review, gaps and attention. Read it and state its exact reporting period. The file stays in drafts. Never send it.

Start with the relevant read and run the one CLI: `npm run assortment -- draft-range-review --store="<store code or ID>" --json`. For writes, supply the required fields above and the real operator. Use help for the complete flags. List ambiguous candidates and let the operator select. Present dates, currency, unknown values and source limitations with the result. Never send, publish or change an external system.
