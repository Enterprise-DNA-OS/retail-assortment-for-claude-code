# review-store

Use --store, --due, --reason and --actor to record the next review date after reading the current store record. The old value and reason are retained in history.

Start with the relevant read and run the one CLI: `npm run assortment -- review-store --store="<store code or ID>" --json`. For writes, supply the required fields above and the real operator. Use help for the complete flags. List ambiguous candidates and let the operator select. Present dates, currency, unknown values and source limitations with the result. Never send, publish or change an external system.
