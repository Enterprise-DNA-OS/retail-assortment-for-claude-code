# history

Read the recorded operator events. Typed names provide attribution and do not authenticate a user.

Start with the relevant read and run the one CLI: `npm run assortment -- history --store="<store code or ID>" --json`. For writes, supply the required fields above and the real operator. Use help for the complete flags. List ambiguous candidates and let the operator select. Present dates, currency, unknown values and source limitations with the result. Never send, publish or change an external system.
