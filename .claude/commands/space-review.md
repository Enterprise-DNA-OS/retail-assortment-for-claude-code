# space-review

Compare sales per facing and per metre of linear product frontage. Width times facings is a simple reported-width measure, not a shelf plan. Zero facings or missing width produce unknown productivity.

Start with the relevant read and run the one CLI: `npm run assortment -- space-review --store="<store code or ID>" --json`. For writes, supply the required fields above and the real operator. Use help for the complete flags. List ambiguous candidates and let the operator select. Present dates, currency, unknown values and source limitations with the result. Never send, publish or change an external system.
