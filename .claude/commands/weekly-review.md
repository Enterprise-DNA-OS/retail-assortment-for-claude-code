# Weekly assortment review

Run range-review, gaps and attention for the requested store, with --json. Then read margin-review and slow-movers where the first three reveal a problem. State the source window and currency. Separate missing observations from zero sales and missing costs from zero cost. Draft the review with draft-range-review, naming the output file. The operator decides the range changes. Nothing sends.
